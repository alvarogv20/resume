# Perfil maestro y revisiones

El propietario aceptó el perfil actual como maestro el 10 de septiembre de 2026.
Fuente inicial: `base.tex`, commit `97e5059`. No se han agregado competencias desde ofertas.

Edita `profile.yaml` para corregir o ampliar tu trayectoria. Mantén identificadores
estables en los hechos que sigan siendo los mismos; añade IDs nuevos para hechos nuevos.
Actualiza `version`, `reviewed_on`, `source` y este registro cuando revises el perfil.
Los resultados antiguos conservan el hash del perfil utilizado y no se regeneran solos.
El proceso nunca escribe en este archivo ni en el perfil maestro.

No incluyas correo, teléfono ni LinkedIn aquí: este fork es público.
Los documentos privados que acrediten un hecho deben permanecer fuera del repositorio.
